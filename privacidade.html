Política de Privacidade

Última atualização: 18 de novembro de 2026

O Clip Watcher é um programa que roda no computador do próprio usuário. Esta política explica quais dados ele usa, para quê, e onde eles ficam.

1. Dados que o Clip Watcher acessa

  • Contas das redes sociais (YouTube, TikTok e Instagram), somente quando o usuário as conecta pelo login oficial de cada rede. O app recebe um código de acesso (token) com as permissões que o usuário autorizar.
  • Informações básicas do perfil: nome de exibição ou nome de usuário, para mostrar qual conta está conectada.
  • Vídeos e textos criados pelo usuário: os clipes, títulos, descrições e hashtags que o usuário escolhe publicar.
  • Transmissões públicas que o usuário escolhe acompanhar (vídeo, áudio e o chat público), para identificar momentos e cortar clipes.

2. Como os dados são usados

  • Para publicar ou agendar os vídeos que o próprio usuário mandou publicar.
  • Para mostrar no app o estado das publicações (publicado, agendado, erro).
  • O Clip Watcher não publica nada sem uma ação ou configuração do usuário, não lê mensagens privadas, não coleta dados de seguidores e não vende nem compartilha dados com terceiros.

3. Onde os dados ficam

Tudo fica no computador do usuário. Os códigos de acesso são guardados criptografados com a proteção de dados do Windows (DPAPI), legíveis apenas pela conta do usuário naquele computador. O Clip Watcher não tem servidores e não envia dados para o desenvolvedor. Os vídeos são enviados diretamente do computador do usuário para a rede social escolhida.

4. Serviços de terceiros

Ao publicar, os dados são enviados às próprias redes, que seguem as suas políticas: Google/YouTube, TikTok e Instagram/Meta. O uso do YouTube também segue os Termos de Serviço do YouTube.

5. Como remover o acesso e os dados

  • No app, em Contas, clique em Desconectar: o código de acesso é apagado do computador.
  • Você também pode revogar o acesso direto nas redes: Google, TikTok (Configurações > Segurança > Apps e serviços) e Instagram (Configurações > Apps e sites).
  • Veja também a página de Exclusão de dados.
